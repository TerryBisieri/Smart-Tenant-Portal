# Alcove – Smart Tenant Portal

A web-based property management platform designed to simplify interactions between landlords, prospective tenants and existing tenants.

## About the Project

Alcove is a Smart Tenant Portal developed to address challenges associated with traditional rental property management. The platform provides a centralized system where prospective tenants can discover available properties, tenants can access tenancy information, and landlords can manage their properties and tenants.

The project aims to improve accessibility, communication and efficiency in residential property management.

## Key Features

### Prospective Tenants
- Browse available rental properties.
- Search and filter properties based on preferences such as location and budget.
- Explore property information.

### Tenants
- Access a dedicated tenant dashboard.
- View rental and tenancy information.
- Access lease documents.
- Track maintenance requests.

### Landlords
- Access a landlord dashboard.
- Manage property listings.
- View and manage tenant information.
- Access property management information and reports.

## System Architecture

The application uses a frontend-backend architecture.

- The React frontend provides the user interface.
- The Express.js backend handles application requests and business logic.
- Firebase and MongoDB support application data management.
- Axios facilitates communication between the frontend and backend services.

## Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate into the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

3. Install frontend dependencies:

```bash
cd frontend
npm install
```

4. Start the frontend:

```bash
npm run dev
```

5. Open another terminal and navigate to the backend directory:

```bash
cd backend
npm install
```

6. Start the backend using the available development script:

```bash
npm run dev
```

**Note:** Replace the directory names and startup commands above with the actual names and scripts in your repository. Configure the required environment variables and Firebase/MongoDB credentials before running the application.
